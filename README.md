# Лабораторная №1 — одномерная оптимизация

Сайт по `../МетОпт_ЛР1.pdf`: все 10 вариантов таблицы 3.2, восемь методов, два режима сравнения, график, независимая проверка минимума и пошаговые вычисления. Все вычисления выполняются в браузере без серверной части и внешних библиотек.

## GitHub Pages

Адрес сайта: https://daredevilg7.github.io/optimisation1/.

Репозиторий: https://github.com/daredevilg7/optimisation1.

После каждого push в `main` GitHub Actions проверяет расчёты и синтаксис JavaScript, затем публикует только каталог `dist`. В настройках репозитория Pages выбран источник GitHub Actions. Методичка, внутренние рабочие документы и файлы конфигурации прежнего Sites-хостинга исключены из Git и публикации.

## Открыть локально

Откройте `dist/index.html` в браузере. Установка зависимостей не требуется.

Альтернативный запуск по HTTP из папки `site`:

```sh
python3 -m http.server 4173 --directory dist
```

Адрес: http://localhost:4173/.

## Проверить расчёты

```sh
node --test tests/solver.test.cjs
```

Проверки сопоставляют минимум всех 10 вариантов с независимо вычисленными корнями аналитической производной; проверяют длину интервала и включение минимума для каждого применимого метода, ограничения бюджета N и недопустимые параметры.

## Файлы

- `dist/solver.js` — функции вариантов, производные, независимая проверка глобального минимума и реализация алгоритмов.
- `dist/app.js` — выбор варианта и параметров, таблица, график, шаги, аналитические пояснения.
- `dist/index.html` и `dist/style.css` — русскоязычный адаптивный интерфейс.
- `dist/methodica.pdf` — локальная копия методички, исключённая из Git и публикации.

## Соглашения

В таблице для сравнения используется единая трактовка ε как гарантированной погрешности середины итогового интервала: L ≤ 2ε. В методичке у золотого сечения и парабол указан более строгий порог L ≤ ε. Эта адаптация явно пояснена на сайте.

Каждый фактический вызов функции внутри поиска входит в счётчик, производные считаются отдельно. Итоговая оценка f(x̃) и независимая проверка ответа не входят в бюджет поиска. Неполный блок не выполняется. Для метода парабол включена предварительная локализация; при машинном совпадении значений сохраняется последний достоверный интервал. Защитные шаги отмечены в таблице.

Касательные не применяются к варианту 6 из-за внутреннего излома и варианту 10 из-за отсутствия выпуклости на исходном отрезке. Вариант 10 также не унимодален на [0,3]; его глобальный минимум проверяется по стационарным точкам и концам отрезка, а ограничения интервальных методов указаны явно.

Другого отдельного задания в предоставленной папке не обнаружено; сайт не содержит выдуманных условий.
